# Prompt legado

Este arquivo não é mais usado para iniciar ciclos autônomos. O coordenador da sociedade usa os papéis versionados em `ops/agent-society/prompts/` e contabiliza toda sessão no limite compartilhado de oito horas ativas por dia.

Inicie ciclos somente por `python3 ops/agent-society/runner.py once` ou pelo serviço `clareira-agent-society.service`. Papéis individuais não criam ciclos adicionais, não alteram o coordenador e não iniciam serviços.
